# Judul Proyek: Edunation-Hero: Transformasi Digital Warisan Ki Hajar Dewantara
## Nama Tokoh: Ki Hajar Dewantara

### Alasan Memilih Tokoh:
Ki Hajar Dewantara bukan sekadar simbol sejarah, melainkan arsitek utama pendidikan di Indonesia yang menekankan bahwa pendidikan adalah hak segala bangsa. Saya memilih beliau karena filosofi "Ing Ngarsa Sung Tulada" sangat relevan dengan peran teknologi saat ini, di mana sebuah platform digital harus mampu menjadi teladan dan memberikan kemudahan akses informasi bagi setiap pelajar. Sebagai mahasiswa Informatika, proyek ini adalah upaya saya untuk mengimplementasikan semangat perjuangan beliau ke dalam bentuk antarmuka modern yang inklusif dan edukatif.
